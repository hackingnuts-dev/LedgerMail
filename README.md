# LedgerMail for iPhone

Private iPhone Gmail and finance-tracking project.

## Scope
- Gmail OAuth 2.0 read-only sign-in and inbox search
- Monthly payment candidates from email receipts
- Credit-card and recurring bill candidates
- Review and confirm transactions before monthly totals
- SwiftUI interface and explicit authentication/sync/review states

## Build and distribution
This repository is in setup. The complete SwiftUI source project is prepared as a ZIP in the ChatGPT conversation, but has not yet been uploaded here. No IPA or TestFlight release has been built.

Native installation without Developer Mode should use TestFlight, which requires an Apple Developer account, signing, and App Store Connect upload. Google Gmail restricted-scope OAuth setup is also required.

**Privacy:** Do not commit Gmail messages, access tokens, certificates, financial data, or provisioning files.
